# ETF 成交额跟踪器 · GitHub Pages 静态版

纯静态页面：行情由浏览器直连公开接口获取，交易时段每 20 秒自动刷新，无需服务器，可直接托管在 GitHub Pages。

## 部署到 GitHub Pages

1. 新建一个公开仓库。
2. 把本目录下所有文件（含 `.github/` 隐藏目录）上传到仓库根目录。
3. 进入仓库 **Settings → Pages → Build and deployment**：
   - Source 选 **Deploy from a branch**
   - Branch 选 `main`，目录选 `/ (root)`，保存。
4. 等待部署完成，访问 `https://<你的用户名>.github.io/<仓库名>/`。

本地预览也可以：在本目录运行 `python -m http.server 8000`，然后打开 `http://localhost:8000/`。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构与样式 |
| `app.js` | 实时行情、指标计算、图表与表格渲染 |
| `data/config.js` | 24 只 ETF 的静态名单、历史份额种子、日内进度与 20 日均额种子 |
| `data/shares.js` | GitHub Actions 定期追加的份额快照（`window.ETF_SHARE_UPDATES`） |
| `tools/backfill_shares.py` | 用沪深交易所官方按日规模数据回填缺失日期的份额 |
| `tools/update_shares.py` | 抓取交易所官方份额并追加快照（失败时回退公开行情） |
| `.github/workflows/update-shares.yml` | 每交易日两次更新份额快照 |

## 数据口径

- **实时行情**：腾讯 `qt.gtimg.cn`，JSONP 直连，交易时段每 20 秒刷新；非交易时段每分钟检查开盘/收盘切换。
- **20 日均额**：首次访问时抓取腾讯日 K（最近 40 日），用成交量 × 当日 OHLC 均价估算成交额，取最近 20 个交易日均值，按日缓存在浏览器 `localStorage`。抓取失败时回退到种子快照，并在状态栏标明。
- **同时点对齐**：盘中用新浪 5 分钟 K 线（以 `sh510300` 为代表）计算近 20 个交易日的日内累计成交额曲线，把分母按历史同时点进度同比例缩小，避免拿半天数据比全天基准。
- **主动买卖方向**：`(外盘 − 内盘) ÷ (外盘 + 内盘) × 成交额`，仅为逐笔成交方向推算，**不是资金净流入、不是申赎、不含大宗交易**。
- **份额**：上交所 `query.sse.com.cn` 与深交所 `www.szse.cn` 官方每日基金规模（单位万份），交易所 T 日晚更新、T+1 早间定稿；份额变化市值 = (本次份额 − 上一交易日份额) × 现价，为估算值，以基金公司公告为准。**没有公开的实时份额源，盘中显示最近一次官方日终值。**
- **份额图表**：由历史快照种子、交易所回填数据与 Actions 续写数据组成，最新日期以页面显示为准。GitHub 对长期无活动的仓库会暂停定时任务，可在 Actions 页面手动触发恢复。

`data/config.js` 中的静态名单与历史份额种子来自历史快照，仅作数据基线，**不代表当前持仓**。
